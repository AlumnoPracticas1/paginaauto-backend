# paginaauto-backend

Backend del proyecto PaginaAuto.

## Contenido
- `backend/` — API Express (Node.js).
- `cliente-escucha/` — script `error_capture.js` que se incrusta en webs cliente para enviar errores al backend.
- `github-app/` — integración con GitHub (también disponible como router `/github` dentro de backend).
- `DEPLOY.md` — notas de despliegue.

## Frontend
El panel/UI vive en otro repo: **paginaauto-frontend**.
